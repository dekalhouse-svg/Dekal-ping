Ajouter ou modifier un site

  1. Ouvrez votre dépôt GitHub DEKAL-PING.
  2. Ouvrez le fichier servers.json, puis appuyez sur le crayon pour le modifier.
  3. Ajoutez une entrée dans la liste servers, en respectant la syntaxe JSON, puis validez avec Commit changes.
  4. GitHub Actions lancera une vérification après la modification, puis continuera selon le calendrier prévu.

Les URL et les résultats sont publics dans ce dépôt public. N'y placez aucun mot de passe, jeton ou URL contenant des informations secrètes.
